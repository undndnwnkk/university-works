# Лабораторная работа №2 — рекомендательная система видеоигр

Программа на Python загружает онтологию видеоигр из файла `video_games.owx`
(OWL/XML — формат экспорта Protege), ведёт короткий диалог с пользователем,
превращает его ответы в условия запроса к онтологии и выдаёт рекомендации с
объяснением, почему игра подошла.

## Состав проекта

- `video_games.owx` — онтология из первой лабораторной
  (`../first/ontology/video_games.ttl`), дополненная для рекомендаций и
  сохранённая в формате OWL/XML;
- `main.py` — загрузка онтологии, диалог, парсинг строки, построение и
  выполнение запроса, вывод рекомендаций;
- `test_main.py` — 14 автоматических тестов;
- `REPORT.md` — краткое описание для защиты;
- `report/report.pdf` — отчёт по шаблону модуля (исходник — `report/report.html`);
- `EXPLANATION.md` — объяснение простым языком и ответы на вопросы.

## Запуск

Нужен только Python 3, сторонние библиотеки не используются
(`.owx` — это XML, он читается стандартным модулем `xml.etree`).

```bash
python3 main.py              # диалог
python3 -m unittest -v       # тесты
protege video_games.owx      # посмотреть онтологию в Protege
```

## Пример диалога

```
Онтология video_games.owx загружена: 20 игр.
> Мне 13 лет, мне нравятся: RPG, инди-игры
Как вы любите играть? (один / с друзьями / неважно): один
Вы новичок в играх? (да / нет): да

Запрос к онтологии: Game and minAge <= 13 and SingleplayerGame and not CompetitiveGame and not HardGame and (hasGenre value rpg or IndieGame)
Рекомендую:
  - Undertale (совпало: RPG, инди)
  - Hades (совпало: инди)
  - Outer Wilds (совпало: инди)
  - Stardew Valley (совпало: инди)
  - Terraria (совпало: инди)
```

## Формат ввода

```
Мне <число> <год|года|лет>, мне нравятся: <интерес>, <интерес>, ...
```

Регистр букв и лишние пробелы не важны. Интересы должны совпадать со словами
из списка целиком (поиск по подстроке не делается):

RPG / рпг / ролевые игры, инди / инди-игры, сюжетные игры,
соревновательные игры / киберспорт, уютные игры / спокойные игры,
экшен / экшены, головоломки, платформеры, песочницы, симуляторы,
стратегии, шутеры, приключения, спортивные игры, MOBA.

## Что добавлено в онтологию по сравнению с первой лабой

- свойство-данные `minAge` (Game → xsd:integer, функциональное) — возраст
  по PEGI для всех 20 игр;
- класс `HardGame ⊑ Game` — сложные игры (Celeste, Hollow Knight, Dark Souls III);
- жанры `rpg`, `shooter`, `strategy`, `adventure`, `sport` и 17 новых
  утверждений `hasGenre` (в первой лабе жанр был только у 7 игр).

Онтология проверена reasoner'ом HermiT 1.4.3 из Protege: непротиворечива,
318 аксиом.
