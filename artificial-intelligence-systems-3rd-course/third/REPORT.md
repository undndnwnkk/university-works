# Отчёт по лабораторной работе №3 (кратко)

Полный отчёт — `report/report.pdf`, все числа — `results.md`.

## Данные

Student Performance: 10 000 строк, 5 признаков (`Hours Studied`,
`Previous Scores`, `Extracurricular Activities`, `Sleep Hours`,
`Sample Question Papers Practiced`), цель — `Performance Index` (10–100).
Пропусков нет, 127 дубликатов удалено (осталось 9873).

## Предобработка

1. Пропуски: медиана для чисел, мода для категорий (в данных их нет).
2. `Extracurricular`: No → 0, Yes → 1.
3. Разбиение 80/20, seed 42 (7898 / 1975).
4. z-нормировка по статистикам обучающей выборки.

## Метод

`Q(B) = Σ(yᵢ − ŷᵢ)² → min` ⇒ `(XᵀX)B = XᵀY`, система решается своим методом
Гаусса с выбором главного элемента. Качество — `R² = 1 − SS_res / SS_tot`.

## Результаты

| Модель | Признаки | R² train | R² test | RMSE |
|---|---|---|---|---|
| 1 | все | 0.9887 | **0.9885** | 2.05 |
| 2 | Hours + Previous | 0.9859 | 0.9851 | 2.33 |
| 3 | без Previous | 0.1469 | 0.1371 | 17.74 |
| 4 (бонус) | все + Hours·Previous + Hours² | 0.9887 | 0.9885 | 2.05 |

Уравнение модели 1:
`Performance = −33.92 + 2.85·Hours + 1.018·Previous + 0.62·Extracurricular + 0.47·Sleep + 0.19·Papers`

## Выводы

- Главный признак — `Previous` (один даёт R² = 0.83), второй — `Hours`.
  Вдвоём они объясняют 98.5 % дисперсии.
- `Sleep`, `Papers`, `Extracurricular` поодиночке R² ≈ 0, но в полной модели
  снижают RMSE с 2.33 до 2.05.
- Без `Previous` модель почти бесполезна (R² = 0.14).
- Переобучения нет: R² на train и test отличается < 0.01.
- Синтетические признаки ничего не добавили — зависимость линейная
  и аддитивная (коэффициенты при них ≈ 0).
