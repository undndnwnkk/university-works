# АКГ, ЛР-4 — Моделирование цветных изображений (построение спектра по цвету)

Выполнили: Коршун Артем, Быков Лев (P3319). Проверил: Жданов Дмитрий Дмитриевич.

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python app.py        # графический интерфейс
.venv/bin/python lab4.py       # без интерфейса: серия расчётов -> results/
```

> В Fedora системный Pillow идёт без `ImageTk` (нужен пакет `python3-pillow-tk`),
> поэтому проще запускать из venv, как выше.

## Состав

* `app.py` — интерфейс (tkinter): ввод параметров, image_A / image_1 / image_2, спектрограммы, таблица, числа.
* `lab4.py` — вычислительное ядро.
* `cie_data.py` — таблицы CIE 1931 (x̄, ȳ, z̄) и D65, 380–780 нм, шаг 10 нм.
* `results/` — результаты для сценариев `white` (белые источники D65), `colored` (A + синий гаусс),
  `colored-sphere` (доп. опыт с цветной сферой) × базисы `box` / `gauss` / `delta`.
* `report/` — отчёт (.docx, .pdf).
* `ОБЪЯСНЕНИЕ.md` — объяснение лабы простым языком, термины, разбор кода.
