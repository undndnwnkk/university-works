# ЛР2. Документация

- [Основной ноутбук: ЛР1 + ЛР2](../lr2_credit_score_eda.ipynb).
- [Памятка по каждому действию](summary.md) – требования, основа из ЛР1, наши действия и вопросы с ответами.
- [Подробный разбор](lr2_credit_score_eda_explained.ipynb) – объяснение команд, расчётов и графиков.

В основном ноутбуке первая часть скопирована из ЛР1 целиком, включая вывод и результаты.
Изменены только пути: исходники читаются из `../dataset-intro/data`, очищенные таблицы
сохраняются в `data/processed`. ЛР2 продолжает готовую таблицу `train_clean`.
Исходный ноутбук в `dataset-intro` не изменён.

Структура ЛР2 по заданию:

1. Изучение распределений признаков: гистограммы, проверка нормальности, оставшиеся выбросы.
2. Корреляционный анализ: корреляционная матрица Спирмена и heatmap.
3. Поиск закономерностей: различия между классами рейтинга (гипотезы H1–H5), временные и сезонные паттерны.
4. Визуализация данных: гистограммы и боксплоты по классам, violin, boxen, диаграммы рассеяния,
   категориальные признаки, heatmap взаимодействия; остальные графики находятся рядом с расчётами.

После анализа приведены результаты гипотез и вывод по ЛР2.
Памятка следует этому же порядку; у каждого действия четыре коротких пункта.

## Запуск основного ноутбука

Из папки `eda-visualization`:

```bash
python3 -m pip install -r requirements.txt
python3 -m jupyterlab lr2_credit_score_eda.ipynb
```

Выполнять ячейки сверху вниз. Результаты и графики уже сохранены в ноутбуке.
Исходные данные лежат в `../dataset-intro/data/`, очищенные – в `data/processed/`
(папка в `.gitignore`, создаётся при запуске), двенадцать итоговых таблиц ЛР2 – в `results/`.

## Запуск подробного разбора

Отдельно, из папки `eda-visualization/docs`:

```bash
python3 -m jupyterlab lr2_credit_score_eda_explained.ipynb
```

Подробный разбор читает очищенную таблицу из `../../dataset-intro/credit_score_train_clean.csv`
и сохраняет итоговые таблицы в общую папку `../results`.

## Итоговые таблицы `results/`

| Файл | Содержание |
|---|---|
| `descriptive_stats.csv` | Количество, среднее, медиана, разброс, минимум, максимум, асимметрия |
| `normality.csv` | Асимметрия, эксцесс и тест Д'Агостино–Пирсона на срезе |
| `outliers_iqr.csv` | Границы IQR и число выбросов по признакам |
| `correlation_matrix.csv` | Матрица Спирмена признаков и ранга рейтинга |
| `score_correlations.csv` | Корреляция каждого признака с рейтингом, по убыванию модуля |
| `hypothesis_tests.csv` | Краскел–Уоллис / χ², размеры эффекта, медианы классов |
| `factor_ranking.csv` | Сопоставимая сила связи, кандидаты в топ-5 |
| `score_by_month.csv` | Доли классов по месяцам |
| `medians_by_month.csv` | Медианы ключевых признаков по месяцам |
| `score_transitions.csv` | Матрица переходов рейтинга между соседними месяцами |
| `score_by_season.csv` | Доли классов по сезонам |
| `hypotheses.csv` | Итог по гипотезам H1–H5 |
