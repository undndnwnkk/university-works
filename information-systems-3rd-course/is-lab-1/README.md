# RouteHub — информационная система маршрутов

Учебное Jakarta EE 10 приложение для управления объектами `Route`. Интерфейс реализован на Jakarta Faces и CDI Managed Beans, бизнес-логика — в EJB, хранение — JPA/Hibernate + PostgreSQL.

## Возможности

- CRUD маршрутов в отдельных интерфейсах: таблица, карточка объекта и модальные формы;
- вывод связанных `Location`, выбор уже существующих локаций при создании;
- серверная пагинация, сортировка и поиск по неполному совпадению названия/локаций;
- информативная клиентская и серверная валидация;
- WebSocket-обновление открытых клиентов после создания, изменения и удаления;
- безопасное переназначение связей через `route_links` при удалении;
- пять специальных операций, реализованных функциями PostgreSQL и вызываемых из бизнес-слоя.

## Быстрый запуск

Понадобится Docker с Compose:

```bash
docker compose up --build
```

После успешного запуска интерфейс доступен на <http://localhost:8080/routes/>. PostgreSQL инициализируется файлами из `db/init`, включая демонстрационные данные.

Остановить приложение:

```bash
docker compose down
```

Чтобы также удалить локальный том БД и повторно применить init-скрипты:

```bash
docker compose down -v
```

## Кафедральный PostgreSQL

На сервере используются параметры `DB_HOST=pg`, `DB_NAME=studs`, а логин и пароль совпадают с учётными данными сервера. Пример переменных находится в `.env.example`. Перед первым запуском примените SQL под своим пользователем:

```bash
psql -h pg -d studs -f db/init/001_schema.sql
psql -h pg -d studs -f db/init/002_seed.sql
```

Затем настройте JNDI datasource `java:/jdbc/RouteDS` в сервере приложений. В Docker-образе он создаётся автоматически из `DB_*` переменных.

## Сборка и структура

```bash
mvn clean verify
```

Результат: `target/routes.war`, рассчитанный на WildFly 35+ или другой Jakarta EE 10 сервер.

- `domain` — JPA-сущности и ограничения Bean Validation;
- `repository` — запросы Hibernate/JPA и вызовы функций БД;
- `service` — транзакционная бизнес-логика;
- `web` — JSF managed beans;
- `websocket` — синхронизация клиентов;
- `db/init` — DDL, ограничения, функции и начальные данные.

## Специальные функции БД

`delete_one_route_by_rating`, `max_rating_route`, `routes_rating_less_than`, `find_routes_between`, `add_route_between`. Дополнительно `delete_route_with_replacement` гарантирует перенос входящих связей перед удалением.
